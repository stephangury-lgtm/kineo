# IFSI gamification alignment

Objectif : aligner le parcours IFSI sur les mécaniques déjà utilisées par Kineo IFMK France, sans verrouiller artificiellement les semestres.

- Tous les semestres restent consultables dès qu'ils contiennent du contenu publié.
- La progression est informative (couverture, fiches lues, quiz répondus), jamais bloquante.
- Les réponses IFSI alimentent XP, niveau, série et badges du compte commun.
- Challenge du jour IFSI basé uniquement sur des questions IFSI publiées.
- Défis entre amis IFSI basés sur un même lot de questions publiées.
- Les questions restent sourcées par les supports fournis.
