## Règle de refonte

Ne pas viser un nombre artificiel d'images. Un visuel peut être partagé uniquement s'il montre réellement la structure demandée avec le cadrage approprié. Chaque asset doit conserver sa source, sa licence et son attribution.

## Hotspots

Le code actuel calcule les coordonnées depuis le rectangle du bouton conteneur (`event.currentTarget`) et non depuis le rectangle réel de l'image. Avant publication d'un hotspot :
1. calculer les coordonnées depuis le `<img>` rendu ;
2. utiliser Pointer Events pour souris/tactile ;
3. normaliser/clamp x/y entre 0 et 100 ;
4. vérifier les cibles à 360/390/412 px et desktop ;
5. conserver un rayon de tolérance anatomiquement raisonnable, sans rendre la réponse triviale.
